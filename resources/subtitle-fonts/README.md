# 字幕烧录字体

使用 Google Fonts 提供的 Noto Sans SC，按 SIL Open Font License 1.1 分发。完整许可见同目录 `OFL.txt`。

- 上游版本：`google/fonts` 提交 `2894aab31764f10f29c421bdfd2340d3b382d384`
- 原文件：`ofl/notosanssc/NotoSansSC[wght].ttf`
- 本地名称：`NotoSansSC.ttf`（仅文件名变更，字体内容未修改）
- SHA-256：`a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`

`pnpm subtitle-font:prepare` 下载并校验字体，开发、构建及打包自动执行此步骤。字体二进制不入库；许可、来源说明与准备脚本正常提交。安装包内置字体，处理视频时无需另外安装中文字体；烧录后的成品视频也不依赖该字体文件。
