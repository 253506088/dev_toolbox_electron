# 开发者工具箱 Electron 版

这是 `dev_toolbox` 的 Electron + Vue 3 + TypeScript 重写项目。当前已完成第一期骨架和 11 个文本工具。

## 本地运行

需要 Node.js 24 或更高版本以及 pnpm。

```powershell
pnpm install
pnpm dev
```

## 检查与构建

```powershell
pnpm test
pnpm typecheck
pnpm build
```

开发环境、调试与发布流程见 [开发、调试与发布指南.md](开发、调试与发布指南.md)。

## 微信长截图与语音转文字

Windows 下打开“滚动长截图”，选择微信聊天窗口，调整截图区域，使其覆盖聊天消息，并排除会话列表、标题栏和输入框。支持逐屏截图与连续长截图两种模式。

选择微信时默认启用“自动将语音转为文字”。保留“先回到内容顶部再开始”，点击“开始截图”后，工具先逐屏扫描语音，右键打开菜单，选择实际识别到的“语音转文字”（兼容“转文字”“转文本”），等待文字展开。发生转写后会回到顶部复查，直到整轮没有新增转写，再回顶开始采集，避免文字展开将其他语音挤出视口，也避免消息高度变化混入长图拼接。

- 自动转写依赖微信本身的语音转文字能力。窗口应保持可见，执行过程中避免手动移动鼠标、缩放窗口或切换聊天。
- 使用 Windows 无障碍接口识别控件，并在必要时使用系统 OCR 辅助识别；OCR 回退需要 Windows 中文语言的 OCR 可选功能。未识别出目标菜单时不会按固定位置盲点菜单项。
- 进度区显示已扫描屏数、成功转写数、已展开检查次数和未成功数；重叠页面可能重复检查已展开内容，因此检查次数不是语音总数。明确识别到语音但无法转换、转写失败或超时，会停止正式截图并提示处理后重试。仅由 OCR 推测的时长若没有转写菜单，会跳过该候选，避免把普通文字当成语音。
- 按 `Ctrl+E` 或点击“停止”可中止。预处理阶段停止时尚未生成长图；已经在微信中展开的转写文字会保留。采集阶段停止会保存已抓取内容。
- 如需从当前位置开始，取消“先回到内容顶部再开始”。此时自动转写会关闭，截图范围保持从当前位置向下；重新勾选回顶后可手动启用自动转写。

每次任务在输出目录下创建独立子目录，保存长图、分屏、Markdown 及运行记录。聊天截图和转写可能包含私人信息，建议将输出目录设置在仓库外；仓库根目录默认命名的 `滚动长截图/` 已加入 `.gitignore`。

语音预处理的数量、检查轮次及失败原因单独写入 `voice-conversion-report.json`，不额外记录聊天文字。开发时可按需运行 Windows 原生交互测试；它会短暂显示并操作独立的合成聊天窗口，不使用真实微信聊天：

```powershell
$env:WECHAT_VOICE_NATIVE_TEST = '1'
pnpm exec vitest run tests/wechat-voice-windows.test.ts
Remove-Item Env:WECHAT_VOICE_NATIVE_TEST
```
