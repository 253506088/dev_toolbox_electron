# 开发者工具箱 Electron 版

这是 `dev_toolbox` 的 Electron + Vue 3 + TypeScript 重写项目。当前已完成第一期骨架和 11 个文本工具。

## 本地运行

需要 Node.js 24 或更高版本以及 pnpm。

```powershell
pnpm install
pnpm dev
```

## 检查与构建

Windows 下直接双击根目录的 [一键打包.bat](一键打包.bat)，即可生成安装版和绿色版。脚本会检查 Node.js 24+、同步依赖、准备 FFmpeg，再执行完整打包；完成后自动打开 `dist/`，失败时保留窗口和错误信息。首次使用需要联网，已有 pnpm 或 Corepack 均可运行。找不到 FFmpeg 时，可按窗口提示拖入 `ffmpeg.exe`。

```powershell
pnpm test
pnpm typecheck
pnpm build
```

开发环境、调试与发布流程见 [开发、调试与发布指南.md](开发、调试与发布指南.md)。

## 视频字幕烧录

在“图片与视频 → 视频字幕烧录”中选择文件夹，或选择 / 拖入一个视频。外挂字幕和视频内的文本字幕轨都可处理。文件夹模式只读取当前目录，不递归进入子目录；支持 MP4、MKV、MOV、AVI、WebM、TS 等常见视频和 SRT、ASS、SSA、VTT 等文本字幕。

1. 选择视频所在文件夹，等待程序读取每个视频的内置字幕和同目录外挂字幕。
2. 默认全选视频，并优先推荐简体中文轨；可以取消视频，或在下拉框改选字幕组、简体 / 繁体及其他语言。每个视频只烧录所选的一条轨。
3. 保持“烧录到画面”“自动硬件加速”“保留原分辨率”，点击开始。
4. 在原目录下的 `内嵌字幕处理+原目录名称/` 找到新 MP4。只拷贝新视频到平板即可显示字幕，不需要手动导出字幕、携带字体或在平板上开启字幕轨。

内置 ASS / SSA 及普通文本轨会自动在临时目录提取；MKV 中的字体附件也会按受控文件名读取，用于保留原字幕样式，不改动或另存源视频。PGS / DVD 等图片字幕会标记为当前不支持，不会生成假成功的无字幕成品。内置轨选择只用于烧录；“内置字幕轨”封装模式用于外挂文件，不能重复封装视频里本来已有的轨。

匹配优先识别季数、集数（例如 `S01E02`、`1x02`、`第十二集`），再比较去掉分辨率、编码、发行组等信息后的名称。列表默认全选，可取消、批量调整选择、切换字幕候选或手动选择字幕；低置信度和重复使用的字幕会提示复核。未匹配的项保留在列表，选好字幕后即可处理。

默认选择“烧录到画面”，输出 H.264 / AAC 编码的 MP4。字幕直接成为视频画面的一部分，复制成品到手机、电视或其他设备后，播放器无需识别字幕轨，也无需外挂字幕或字体文件，打开视频即可看到字幕。烧录需要重新编码视频，耗时更长，成品中的字幕无法关闭。程序显示每个文件的进度与失败原因。

默认“自动硬件加速”会先检查实际设备，并用真实编码和当前源格式的短片段预检 Intel Quick Sync 硬解、字幕烧录与硬编链路。本机 Core Ultra 5 125H / Intel Arc 的 4K HEVC Main10 输入已验证可用；默认保留原分辨率，兼容性输出为 H.264 8-bit / AAC。硬件不可用或中途失效会明确失败，不能悄悄改成耗时数小时的 CPU 编码。需要时可主动选择 CPU 快速编码；1080p 速度模式也必须主动选择，才会缩小视频。

每项显示实际编码器、解码器、实时更新的 FPS / 倍速统计、耗时和动态预计剩余时间。初始化阶段不猜 ETA，长时间没有新输出时不保留过时统计；编码结束后的 MP4 索引整理和成品保存单独显示，进度达到 100% 仍会等待文件完成才标记成功。字幕效果、场景及磁盘状态会影响速度，短片段 FPS 不作为整集承诺。

需要保留可开关字幕时，可主动选择“内置字幕轨”。该模式把字幕文本存进视频文件，复制成品也不依赖原外挂文件，但播放器必须支持并开启字幕轨；默认 MKV 保留 ASS 样式，可选 MP4 文本轨。高级设置支持字幕编码和时间偏移：正值让字幕晚出现，负值让字幕提前。

原视频和外挂字幕不会修改。输出放在原目录下的 `内嵌字幕处理+原目录名称/`，同名文件自动追加序号；取消或失败会清理未完成的视频，已成功的结果保留。可以切换其他页签继续使用工具箱，后台处理持续进行。生成的视频、测试素材、截图和诊断结果已通过 `.gitignore` 排除。

开发、构建和打包自动准备并校验 OFL 授权的 Noto Sans SC 中文字体，安装包会内置字体及许可证；烧录完成后的视频不再依赖字体。首次准备资源需要联网，已验证的本地字体会复用。

开发验收可先运行 `pnpm ffmpeg:prepare`、`pnpm build`，再运行 `node scripts/smoke-subtitles.cjs`；打包后运行 `node scripts/smoke-subtitles.cjs --app dist/win-unpacked/resources/app.asar`。脚本使用独立用户数据和合成视频，验证默认烧录、视频选择与匹配、后台处理、手动字幕及重复输出；将成品单独复制改名并隔离源文件后，只解码视频流及用普通 HTML5 播放器验证字幕确实显示在画面上。截图和报告保存在 `test-results/`。`pnpm test` 还覆盖 ASS 样式、中文编码、时间偏移和取消清理；未准备 FFmpeg / 字体时对应真实媒体测试会跳过。

## 微信长截图与语音转文字

Windows 下打开“滚动长截图”，选择微信聊天窗口，调整截图区域，使其覆盖聊天消息，并排除会话列表、标题栏和输入框。支持逐屏截图与连续长截图两种模式。

选择微信时默认启用“自动将语音转为文字”，并从当前位置向下截图。每一屏先检查语音，遇到未展开的语音就调用微信的“语音转文字”（兼容“转文字”“转文本”），确认转写完成、画面稳定后立即截图，再继续向下。无需提前扫描整段聊天，也不会为了转写反复回到最顶部。

如果语音展开使当前内容上移，工具会在附近小幅向上滚动，恢复本屏的内容起点，并重新检查被挤出视口的语音。需要完整聊天记录时，可手动勾选“先回到内容顶部再开始”；回顶只负责选择截图起点，后续仍按每屏处理语音。

- 自动转写依赖微信本身的语音转文字能力。窗口应保持可见，执行过程中避免手动移动鼠标、缩放窗口或切换聊天。
- 使用 Windows 无障碍接口识别控件，并在必要时使用系统 OCR 辅助识别；OCR 回退需要 Windows 中文语言的 OCR 可选功能。未识别出目标菜单时不会按固定位置盲点菜单项。
- 进度区显示已检查屏数、成功转写数、已展开检查次数和未成功数；重叠页面可能重复检查已展开内容，因此检查次数不是语音总数。底边语音的文字展开到截图区域外时，也会通过实际“收起文字”菜单确认完成。
- 明确识别到语音但无法转换、转写失败、超时或无法恢复本屏起点时，会停止并保存此前已截图内容，避免把不完整画面拼入长图。仅由 OCR 推测的时长若没有转写菜单，会跳过该候选。
- 按 `Ctrl+E` 或点击“停止”可中止，并保存此前已抓取内容；首屏完成前停止则没有截图产物。已经在微信中展开的转写文字会保留。从当前位置开始同样支持自动转写。

每次任务在输出目录下创建独立子目录，保存长图、分屏、Markdown 及运行记录。聊天截图和转写可能包含私人信息，建议将输出目录设置在仓库外；仓库根目录默认命名的 `滚动长截图/` 已加入 `.gitignore`。

逐屏语音处理的数量、完成状态及失败原因单独写入 `voice-conversion-report.json`（`mode: per-viewport`），不额外记录聊天文字。开发时可按需运行 Windows 原生交互测试；它会短暂显示并操作独立的合成聊天窗口，不使用真实微信聊天：

```powershell
$env:WECHAT_VOICE_NATIVE_TEST = '1'
pnpm exec vitest run tests/wechat-voice-windows.test.ts
Remove-Item Env:WECHAT_VOICE_NATIVE_TEST
```

## SQL 与 MyBatis 模板

SQL 格式化支持 `#{time}`、`${tableName}`、带 `jdbcType` 或属性索引的参数，以及常见的 `<if>`、`<where>`、`<foreach>` 等动态 SQL 标签和 CDATA。模板参数、标签属性和 SQL 字符串原样保留；也可使用“XML 编码 / XML 解码”按钮转换复制内容。

SQL 解析在后台线程执行，运行期间仍可编辑。格式错误只显示简短提示并保留原文；修正后可直接重试，超时会释放线程。处理期间编辑或清空输入后，旧结果不会覆盖新内容。

## 文件管理器容量统计

右侧面积图直接显示名称、容量和占比；顶部展示当前已统计总量、精确字节数、剩余统计项和排除的重复大小。悬停可查看完整路径与按路径累加的逻辑大小。

容量按文件内容统计：同一硬链接文件在当前导航目录中只计入一次，跨子目录也去重；内容相同但独立存储的文件分别计数。共享内容按列表顺序归属，进入子目录后会在新范围内重新统计，因此子目录独立打开时的大小可能不同于父目录中的计入大小。符号链接和目录联接点不跟随，无法读取的内容会标注为部分结果。此数值不是包含压缩、稀疏文件和分配单元差异的磁盘实际占用空间。
