# 开发者工具箱 Electron 版

这是 `dev_toolbox` 的 Electron + Vue 3 + TypeScript 重写项目。当前已完成第一期骨架和 11 个文本工具。

## 本地运行

需要 Node.js 24 或更高版本以及 pnpm。

```powershell
pnpm install
pnpm dev
```

## 检查与构建

Windows 下直接双击根目录的 [一键打包.bat](一键打包.bat)，即可生成安装版和绿色版。脚本会检查 Node.js 24+、同步依赖、准备 FFmpeg，再执行完整打包；完成后自动打开 `dist/`，失败时保留窗口和错误信息。首次使用需要联网，已有 pnpm 或 Corepack 均可运行。找不到 FFmpeg 时，可按窗口提示拖入 `ffmpeg.exe`。

```powershell
pnpm test
pnpm typecheck
pnpm build
```

开发环境、调试与发布流程见 [开发、调试与发布指南.md](开发、调试与发布指南.md)。

## 微信长截图与语音转文字

Windows 下打开“滚动长截图”，选择微信聊天窗口，调整截图区域，使其覆盖聊天消息，并排除会话列表、标题栏和输入框。支持逐屏截图与连续长截图两种模式。

选择微信时默认启用“自动将语音转为文字”，并从当前位置向下截图。每一屏先检查语音，遇到未展开的语音就调用微信的“语音转文字”（兼容“转文字”“转文本”），确认转写完成、画面稳定后立即截图，再继续向下。无需提前扫描整段聊天，也不会为了转写反复回到最顶部。

如果语音展开使当前内容上移，工具会在附近小幅向上滚动，恢复本屏的内容起点，并重新检查被挤出视口的语音。需要完整聊天记录时，可手动勾选“先回到内容顶部再开始”；回顶只负责选择截图起点，后续仍按每屏处理语音。

- 自动转写依赖微信本身的语音转文字能力。窗口应保持可见，执行过程中避免手动移动鼠标、缩放窗口或切换聊天。
- 使用 Windows 无障碍接口识别控件，并在必要时使用系统 OCR 辅助识别；OCR 回退需要 Windows 中文语言的 OCR 可选功能。未识别出目标菜单时不会按固定位置盲点菜单项。
- 进度区显示已检查屏数、成功转写数、已展开检查次数和未成功数；重叠页面可能重复检查已展开内容，因此检查次数不是语音总数。底边语音的文字展开到截图区域外时，也会通过实际“收起文字”菜单确认完成。
- 明确识别到语音但无法转换、转写失败、超时或无法恢复本屏起点时，会停止并保存此前已截图内容，避免把不完整画面拼入长图。仅由 OCR 推测的时长若没有转写菜单，会跳过该候选。
- 按 `Ctrl+E` 或点击“停止”可中止，并保存此前已抓取内容；首屏完成前停止则没有截图产物。已经在微信中展开的转写文字会保留。从当前位置开始同样支持自动转写。

每次任务在输出目录下创建独立子目录，保存长图、分屏、Markdown 及运行记录。聊天截图和转写可能包含私人信息，建议将输出目录设置在仓库外；仓库根目录默认命名的 `滚动长截图/` 已加入 `.gitignore`。

逐屏语音处理的数量、完成状态及失败原因单独写入 `voice-conversion-report.json`（`mode: per-viewport`），不额外记录聊天文字。开发时可按需运行 Windows 原生交互测试；它会短暂显示并操作独立的合成聊天窗口，不使用真实微信聊天：

```powershell
$env:WECHAT_VOICE_NATIVE_TEST = '1'
pnpm exec vitest run tests/wechat-voice-windows.test.ts
Remove-Item Env:WECHAT_VOICE_NATIVE_TEST
```

## SQL 与 MyBatis 模板

SQL 格式化支持 `#{time}`、`${tableName}`、带 `jdbcType` 或属性索引的参数，以及常见的 `<if>`、`<where>`、`<foreach>` 等动态 SQL 标签和 CDATA。模板参数、标签属性和 SQL 字符串原样保留；也可使用“XML 编码 / XML 解码”按钮转换复制内容。

SQL 解析在后台线程执行，运行期间仍可编辑。格式错误只显示简短提示并保留原文；修正后可直接重试，超时会释放线程。处理期间编辑或清空输入后，旧结果不会覆盖新内容。

## 文件管理器容量统计

右侧面积图直接显示名称、容量和占比；顶部展示当前已统计总量、精确字节数、剩余统计项和排除的重复大小。悬停可查看完整路径与按路径累加的逻辑大小。

容量按文件内容统计：同一硬链接文件在当前导航目录中只计入一次，跨子目录也去重；内容相同但独立存储的文件分别计数。共享内容按列表顺序归属，进入子目录后会在新范围内重新统计，因此子目录独立打开时的大小可能不同于父目录中的计入大小。符号链接和目录联接点不跟随，无法读取的内容会标注为部分结果。此数值不是包含压缩、稀疏文件和分配单元差异的磁盘实际占用空间。
